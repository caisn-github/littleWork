要求1： 生成主公钥：
   安全参数：
   维度 ：n = 512;
   模数 ：q = 2^23; (需要选择一个素数)
   错误分布参数 ： alpha = 0.01 ;

   （随机种子： 32字节）
   public static Matserkey generateMaterKey(byte []seed) {
        首先使用随机种子生成一个加密的安全的伪随机数 random

        然后通过伪随机数生成random 生成主私钥sk（私钥是短向量），sk是一个int数组

        //然后使用格密码的算法：
        1.生成随机矩阵A， int[][]
        2.生成短噪声下向量e , int数组
        3.计算A·sk（格点）
        4.加噪声得到 b = A·sk + e (看起来随机，隐藏sk) ， b是一个多维向量
        于是主公钥  pk_m = (A，b)

        // 于是最终得到了主私钥sk, 主公钥pk_m, 攻击者很难从（A,b）恢复sk, 因为LWE问题是困难的
        // 对于攻击者来说，看到（A,b）,但是由于e的随机性，b看起来像均匀随机的，无法轻易求出sk

        最后由随机种子派生生成链码

 /**
       1.生成随机矩阵A: A:是公钥的一部分，代表一个随机格的基底；A是公开的，但是即使攻击者即使知道A,也很难恢复sk
         A中的每个元素是在模q上随机选取生成的

       2.生成一个短错误向量e, 其元素是从离散高斯分布采样的小随机数
         因为 LWE 的安全性依赖于噪声e, 使得b = A·sk + e看起来是随机的，即使知道A和b, 也很难反推sk,

       3. 计算A·sk : 计算矩阵A和私钥sk的乘机A·sk 再模q

  */

   }
   /*
   示例：
    生成主密钥的示例：
   假定维度n=3, 模数q=17, 私钥sk是小向量，误差e也只是一个小噪声。

   假设根据随机种子生成的主私钥sk为：
   sk = [1, 0 ,  -1]

   A = [
   [3,12,5],
   [6,15,2],
   [9,8,11]
   ]
   A根据模q随机选取

   然后计算b = A*sk
   b'[0] = (3*1 + 12*0 + 5*(-1)) mod 17 = (3 + 0 - 5) mod 17 = -2 mod 17 = 15
   b'[1] = (6*1 + 15*0 + 2*(-1)) mod 17 = (6 + 0 - 2) mod 17 = 4 mod 17 = 4
   b'[2] = (9*1 + 8*0 + 11*(-1)) mod 17 = (9 + 0 - 11) mod 17 = -2 mod 17 = 15

   b' = [15, 4, 15]

   接着生成一个小噪声：
   误差e:
   e = [1, -1, 0] //小噪声

   最后计算b:
    b = b' + e (mod q)
   b[0] = (15 + 1) mod 17 = 16 mod 17 = 16
   b[1] = (4 + (-1)) mod 17 = 3 mod 17 = 3
   b[2] = (15 + 0) mod 17 = 15 mod 17 = 15

   b = [16, 3, 15]

   于是最终的主公钥pk_m是矩阵A和向量b的组合：
   pk_m = (A，b) = (
   [
   [3,12,5],
   [6,15,2],
   [9,8,11]
   ],
   [16,3,15]
   )
  ]
   **/

要求2 : 基于格基伪随机函数LWE-PRF实现密钥派生：
与前面一样的，首先定义安全参数：
        维度 ：n = 256;
        模数 ：q = 4093; (需要选择一个素数)
        错误分布参数 ： alpha = 0.01 ;
        index : 索引号
public static CHildKey deriveChildKey(MasterKey parentKey, int index) {

        准备派生数据：
        parentKey中的主私钥sk，索引index，以及parentKey中的链码chainCode

        拼接数据生成一个派生数据块：
        derivationData = parentKey.sk + parentKey.index + parentKey.chainCode
        // 拼接之后的数据作为哈希函数LWE-PRF的输入，生成一个看似随机的输出，用于后续计算

        然后将拼接好的派生数据转换为密码学安全的伪随机输出，用于后续的矩阵生成和密钥计算(使得密钥派生看似随机但更安全)：
        使用derivationData进行SHA-256的哈希计算，得到哈希值hash
        然后再使用hash构造确定性的随机数器 prfRandom （类似于上一个函数中的seed的作用）

        // 使用格密码的算法:
        1. 使用 prfRandom作为种子生成矩阵H
        2. 使用高斯生成误差矩阵e
        3. 计算子私钥sk:
            sk = parentKey.sk + H*parent.sk + e mod q

        4. 最后计算 b = H*sk + e
        于是子公钥 pk_m = (H，b)

        然后生成新的链码：
        使用新的随机数生成器 prfRandom生成新的chainCode

}
